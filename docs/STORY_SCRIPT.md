# 故事脚本（竖切片）

这是当前可玩剧情，不是完整剧本。所有节点在 `Sim/Content.cs` 的 `DialogueDef` 中，结构与 JSON 一一对应，后续可整体导出。

## 主题

旧世界被尸潮与灵气同时撕开。安全屋里的守夜人阿禾只信“活过今晚”；杂货商老陈只信旧币；天机碑只收晶核。玩家要在生存、交易与修仙之间做取舍。

## 第一幕：醒来

**场景**：守夜人小屋，第 1 天 08:00。玩家在床边醒来，阿禾在屋内。

**阿禾**：
> 你总算醒了。水比血重要——先去弄一瓶干净的水，活过今晚，再谈别的。

选项：

1. 「我会撑过今晚。」→ 设置 `met_ahe`，接取「第一夜」。
2. 「外面还有活人吗？」→ 阿禾说明街口尸群、诊所药品、夜里别点灯；回到 1。
3. 「你为什么留下？」→ 阿禾提到她答应过一个人守住屋子；回到 1。

**任务**：第一夜（收集瓶装水 + 熬过夜晚）→ 奖励《铁布衫》、修为、罐头、悟性。

## 第二幕：诊所的路

**触发**：第一夜完成后再次与阿禾对话。

**阿禾**：
> 诊所的方向我熟。你走前面，我跟着；要是尸群太密，就退回安全屋。

选项：

1. 「一起走。」→ 阿禾跟随，接取「诊所的路」。
2. 「你留在安全屋。」→ 阿禾等待，可再次对话让她跟随。

**任务目标**：

- 抵达社区诊所（坐标约 12, -12，半径 3m）
- 返回安全屋（坐标约 10, 8，半径 3.5m）

**奖励**：悟性 +2、旧币 +35、修为 +45。

**失败/边界**：阿禾没有独立血量（当前竖切片）；尸群会攻击玩家。后续可加“阿禾死亡 → 任务失败/替代对话”。

## 第三幕：老陈与天机碑

**场景**：杂货铺，老陈。

**老陈**：
> 晶核？那东西天机碑收。我这儿只认旧币——活人的钱，才叫钱。

选项：

1. 「看看货。」→ 设置 `met_laochen`，打开 NPC 交易。
2. 「随便问问。」→ 老陈给出三条传闻：北边古井、诊所后门警尸、东边军尸与子弹。

**系统交易**：手机「交易」App → 天机碑石臼。晶核换丹药/绷带/9mm/灵草/御风残卷/筑基丹。

## 第四幕：古井与筑基（预留）

阿禾在「诊所的路」完成后会说：

> 药拿到了，今晚能睡得踏实一点。你身上有股……不一样的气。
>
> 我只会守夜，不会修仙。但你要找的答案，也许在城北那口古井。

选择「教我」→ 设置 `vein_hint`。古井灵脉已在世界中（0, 24），入定获得额外灵气；后续可接「古井」任务链。

## 对话数据结构

```csharp
new DialogueNodeDef {
  Id = "start",
  Speaker = "阿禾",
  Text = "...",
  Choices = {
    new DialogueChoiceDef {
      Text = "一起走。",
      Action = "follow|quest:ahe_escort|flag:ahe_following",
      Next = ""
    }
  }
}
```

`Action` 可串联；`Next` 为空表示结束，否则跳到指定节点。条件字段 `RequiresFlag` / `RequiresItem` 用于分支。

## 扩展建议

- 每个 NPC 一个 `dialogue.<id>`，节点 id 稳定，方便本地化。
- 剧情标记用 `snake_case`；任务/对话/区域共用。
- 对话只做状态变更，不直接操纵 GameObject；表现由 `NpcController` 读 `NpcState`。
- 后续把 `NpcDef/DialogueDef` 导出 JSON，加载后调用同一个 `StorySystem`。
